# Package map

Where things live and what each part is responsible for. Read against the tree on
2026-10-02. The tree itself is [repository-layout.md](repository-layout.md).

## Backend (`backend/`, Go module `github.com/guided-traffic/cowork/backend`)

| Package | Responsibility | Key symbols |
|---|---|---|
| [`api/`](../../backend/api/) (package `apispec`) | The API document, the contract: `openapi.yaml` and one file per path family under it, `components/`, the oapi-codegen configuration, the bundle `openapi.gen.json` (generated) and `embed.go`, which embeds it ([api.md](api.md#the-document)) | `Document` |
| [`cmd/cowork/`](../../backend/cmd/cowork/) | The binary: `serve`, `migrate`, `version`, `help`. Loads the configuration, migrates as the owner role, checks the database, wires store, event hub, storage, API and server, runs the jobs. `run` is separated from `main` so a test drives it with its own environment and writers | `run`, `runServe`, `runMigrate`, `requireForServe`, `checkDatabase`, `runJobs`; `version`/`commit`/`buildTime` (set by the linker) |
| [`internal/api/`](../../backend/internal/api/) | The API: the pipeline in front of the generated server, and one method of `Server` per operation; file by file below | `New`, `Options`, `Server` |
| [`internal/api/apigen/`](../../backend/internal/api/apigen/) | Generated by oapi-codegen v2.8.0 from the bundle: models, the strict server interface, the registration on the mux, the Go client the tests use. Never edited | `StrictServerInterface`, `HandlerWithOptions`, `ClientWithResponses` |
| [`internal/auth/`](../../backend/internal/auth/) | Who a request acts for: the token's shape and hash (`token.go`), the principal and the agent mark (`principal.go`), the authorization of an act (`authorize.go`) | `GenerateToken`, `HashToken`, `WellFormedToken`, `Principal`, `ParseAgentHeader`, `Mark`, `Need`, `Authorize`, `Cap…`, `HardOff…` |
| [`internal/config/`](../../backend/internal/config/) | Every `COWORK_*` variable, its default and its validation. `Load` takes a lookup with the contract of `os.LookupEnv` and reports every invalid value at once, naming the variable, never a secret's value | `Config`, `Storage`, `Load`, `Env…`, `Default…` |
| [`internal/domain/`](../../backend/internal/domain/) | The vocabularies and the rules that need no database: roles and scopes (`domain.go`), ticket vocabularies, keys, urgency rule set v1, link names (`ticket.go`), the transition matrix (`transition.go`), attachment types and file names (`attachment.go`) ([domain.md](domain.md)) | `Role`, `Scope`, `ParseTicketKey`, `FullKey`, `DeriveUrgency`, `UrgencyInputs`, `LinkType.Name`, `ClassifyMove`, `DetectAttachmentType`, `SanitizeFileName` |
| [`internal/events/`](../../backend/internal/events/) | The event hub of one replica: a replay ring per tenant, a filter and a bounded buffer per stream, the per-person limit ([events.md](events.md)) | `Hub`, `New`, `Publish`, `Subscribe`, `SetUp`, `Close`, `Filter`, `Resync`, `Unavailable` |
| [`internal/httpserver/`](../../backend/internal/httpserver/) | The outer handler and the server lifecycle: `/healthz`, `/readyz`, `/api/` handed to the API, a JSON 404 and a 405 for the rest; the request id, the request log, the panic recovery; `Serve` runs until the context ends, runs the shutdown hooks and drains within the timeout | `Options`, `New`, `ListenAndServe`, `Serve` |
| [`internal/markdown/`](../../backend/internal/markdown/) | The canonical Markdown of a ticket, grammar v1, a pure function; golden files in `testdata/` ([markdown-grammar.md](markdown-grammar.md)) | `Render`, `Ticket`, `Question` |
| [`internal/problem/`](../../backend/internal/problem/) | The code catalogue, the one place a problem code is defined, and the RFC 9457 body; `make generate` writes the document's enum and the README table from it | `Code`, `Catalogue`, `Error`, `FieldError`, `New`, `Field`, `Write` |
| [`internal/requestid/`](../../backend/internal/requestid/) | The request id, a UUIDv7, carried through the context | `New`, `With`, `From`, `UUID` |
| [`internal/storage/`](../../backend/internal/storage/) | The attachments' bytes in S3-compatible storage, a minio-go client for one bucket ([storage.md](storage.md)) | `Client`, `New`, `Key`, `Put`, `Get`, `Delete`, `EnsureBucket`, `ErrMissing` |
| [`internal/store/`](../../backend/internal/store/) | PostgreSQL: the pool behind the transaction wrappers, the migrations, the roles check, the list builder, the locks, the jobs, the publication; file by file below ([data-access.md](data-access.md)) | `DB`, `Open`, `Migrate`, `Reader`, `Writer`, `Mutate`, `RunJob`, `Listen` |
| [`internal/store/migrations/`](../../backend/internal/store/migrations/) | The schema, `NNNNNN_<name>.up.sql`, embedded; no down files. `000001_tenants` to `000014_attachments` | — |
| [`internal/store/queries/`](../../backend/internal/store/queries/) | The SQL, one file per aggregate: `read/` becomes `readq`, `write/` becomes `writeq` | — |
| [`internal/store/readq/`, `writeq/`](../../backend/internal/store/readq/) | Generated by sqlc ([`sqlc.yaml`](../../backend/sqlc.yaml)). Never edited | `Queries`, one method per named query |
| [`test/fixture/`](../../backend/test/fixture/) | Persons, tenants, memberships, projects, tickets and tokens written over the administrative connection, past row-level security; never part of the binary ([testing.md](testing.md#fixtures-of-the-integration-tier)) | `Connect`, `DB.Person`, `Tenant`, `Member`, `Project`, `Ticket`, `Token`, `TokenSpec` |
| [`test/devseed/`](../../backend/test/devseed/) | `make dev-seed`: a person, a tenant, an admin membership and a token for the development database | `main` |
| [`test/integration/`](../../backend/test/integration/) | The integration tier (build tag `integration`): PostgreSQL 18 and an S3 server | `TestMain`, `newWorld`, `newAPI` |
| [`tools/problemdoc/`](../../backend/tools/problemdoc/), [`tools/specbundle/`](../../backend/tools/specbundle/) | The generators `make generate` runs first: the problem-code enum and README table; the bundled document | `main` |
| [`sqlc.yaml`](../../backend/sqlc.yaml) | The sqlc configuration: the migrations as schema, `queries/read` → `readq`, `queries/write` → `writeq`, the database enums mapped onto the `domain` types | — |
| [`Containerfile`](../../backend/Containerfile) | Two stages: `golang:1.27.1-alpine` builds the static binary, distroless `static-debian12:nonroot` runs it | — |
| [`.golangci.yml`](../../backend/.golangci.yml) | The linter set; golangci-lint runs from `backend/` | — |

## Frontend (`frontend/`, Angular project `frontend`)

| Path | Responsibility |
|---|---|
| [`frontend/src/app/app.ts`](../../frontend/src/app/app.ts) | The shell: header, router outlet, footer with the backend version and commit (or "backend unreachable") |
| [`frontend/src/app/app.config.ts`](../../frontend/src/app/app.config.ts) | Application providers: router, `HttpClient` with fetch, the global error listeners |
| [`frontend/src/app/app.routes.ts`](../../frontend/src/app/app.routes.ts) | The routes; empty |
| [`frontend/src/app/core/version.service.ts`](../../frontend/src/app/core/version.service.ts) | `GET /api/v1/version`. Its `VersionInfo` type mirrors the document's `Version` schema (`version`, `commit`, `build_time`); the shell reads only `version` and `commit` |
| [`frontend/proxy.conf.json`](../../frontend/proxy.conf.json) | `ng serve` forwards `/api`, `/healthz`, `/readyz` to the backend on `:8080` — `/api` as nginx does; in the container nginx answers `/healthz` itself and `/readyz` with the UI shell |
| [`frontend/nginx/default.conf.template`](../../frontend/nginx/default.conf.template) | The container's nginx configuration: the bundle with `index.html` fallback, immutable hashed assets, its own `/healthz`, `/api/` proxied with its own problem bodies, the unbuffered event stream ([architecture.md](architecture.md#frontend-container)) |
| [`frontend/Containerfile`](../../frontend/Containerfile) | Two stages: `node:26-alpine` builds the bundle, `nginxinc/nginx-unprivileged` serves it; `NGINX_ENVSUBST_FILTER` limits the template substitution to the four variables; `ENV` sets their image defaults and makes the entrypoint export the resolvers |
| [`frontend/eslint.config.js`](../../frontend/eslint.config.js) | The angular-eslint configuration `ng lint` runs |
| [`frontend/angular.json`](../../frontend/angular.json) | The build (`@angular/build:application`, output `dist/frontend/browser`), the test runner (`@angular/build:unit-test`, vitest on jsdom), the dev server with the proxy |

## Delivery

| Path | Responsibility |
|---|---|
| [`Makefile`](../../Makefile) | Every build, generate, test, lint and tooling target, and the local PostgreSQL and MinIO containers; the entry point for CI and developers. Go targets `cd backend`, npm targets `cd frontend`; tools, `bin/` and `coverage/` land at the root ([build-test-lint.md](build-test-lint.md)) |
| [`deploy/helm/cowork/`](../../deploy/helm/cowork/) | The chart: the backend Deployment with the `migrate` init container (owner credential) and the serving container (runtime credential, `COWORK_MIGRATE_ON_START=false`), the frontend Deployment with the nginx variables computed from the backend's limits, the Services, an optional Ingress on the frontend, the database Secrets for inline URLs, one ServiceAccount without a token; the server key and the storage keys come from existing Secrets only. `ci/*-values.yaml` are the shapes CI lints and renders |
| [`.github/workflows/release.yml`](../../.github/workflows/release.yml) | "Test and Release": every gate on push and PR, the generated-files check, the integration tier with PostgreSQL and MinIO, one container-scan leg per image, semantic-release on `main` ([ci-and-release.md](ci-and-release.md)) |
| [`.github/workflows/build.yml`](../../.github/workflows/build.yml) | "Release Docker & Helm": both images with SBOM and scan, the chart to `gh-pages`, on a published release |
| [`.github/workflows/renovate.yml`](../../.github/workflows/renovate.yml) | Self-hosted Renovate, daily |
| [`hack/verify-release-tooling.mjs`](../../hack/verify-release-tooling.mjs) | Drives the semantic-release plugins against a synthetic commit set, so a broken preset/writer pair fails a PR, not a release |
| [`hack/verify-phase-2.sh`](../../hack/verify-phase-2.sh), [`hack/verify_phase_2.py`](../../hack/verify_phase_2.py) | `make verify-phase-2`: both images read-only against PostgreSQL and MinIO, the API driven as a `make dev-seed` agent, the audit view checked |
| [`package.json`](../../package.json) | The semantic-release dependency set (root; the UI has its own `frontend/package.json`) |
